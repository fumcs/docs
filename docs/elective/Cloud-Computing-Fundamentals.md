**Course syllabus:**

This course introduces the basic concepts, architectures, and services of cloud computing, with an emphasis on how cloud platforms support scalable, on-demand computing and storage.

Topics include: service models (IaaS, PaaS, SaaS); deployment models (public, private, hybrid, community); virtualization and containerization; resource provisioning, elasticity, and scalability; cloud storage systems; distributed file systems; and data processing frameworks in the cloud. Security, privacy, and reliability issues in cloud environments are also discussed.

Students are introduced to one or more major cloud platforms (such as AWS, Azure, or Google Cloud) at an introductory level, including basic account setup, virtual machines or containers, storage services, and simple deployment scenarios.
