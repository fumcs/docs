**Course syllabus:**

- Numerical solution of ordinary differential equations with initial conditions. Numerical solution of boundary value problems for differential equations. Numerical solution of partial differential equations using finite difference methods and related techniques. Iterative methods for solving systems of linear equations. Matrix factorizations. Solution of linear least-squares problems. Orthogonal (e.g., QR) factorizations of matrices. Eigenvalue problems and numerical methods for their solution.

**References:**

- Burden, R. L., & Faires, J. D. (2011). Numerical Analysis. Cengage Learning.
