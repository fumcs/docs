**Course syllabus:**

This course introduces the principles and practice of programming applications for mobile devices, with emphasis on modern smartphone platforms.

Topics include: characteristics of mobile computing environments; mobile application architectures and design patterns (including MVC and MVVM); user interface design and usability for small screens; event-driven programming and activity lifecycles; persistent storage (files, preferences, SQLite, and object databases); networking, web services, and RESTful APIs; background execution and concurrency; access to device sensors and location services; offline operation and synchronization; security and privacy considerations; and packaging, deployment, and publication of mobile applications.

The course typically uses at least one major mobile platform (such as Android or iOS) and associated development tools, and includes substantial programming assignments and a term project.
