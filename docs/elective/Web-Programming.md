**Course syllabus:**

- Introduction; course overview; brief history of the Web; HTTP protocol.

- Page design: HTML structure and elements; formatting; links; lists; images; tables; forms; new elements in HTML5.

- Styling with CSS: selectors; inheritance and cascading; design principles; page layout; box model; floats; positioning; pseudo-classes.

- JavaScript: statements and functions; variables and data types; control structures; arrays and objects; DOM model; manipulating elements and styles; event handling and exceptions; jQuery library (selectors, events, effects, animations).

- Data storage: XML concepts and applications; DTD; XSLT transformations; JSON; relational databases; creating databases; SQL query language.

- Server interaction: CGI interface; GET and POST requests; form processing; cookies; AJAX (sending requests, receiving and parsing responses, applications).

- Python for the web: fetching web pages; Python web servers; introduction to WSGI.

- Web architectures: layered architecture; client–server architecture; three-tier architecture; MVC architecture.

- Django framework: basic concepts; installation and setup; components; overall architecture.

- Advanced topics: middleware; performance optimization and compression; caching; authentication; access control; user and group management; security and protection against attacks; cryptography; sessions and session-state storage; compositional approaches; internationalization and localization; translation tools.
