**Course syllabus:**

- Software process models: waterfall model, incremental model, evolutionary model, concurrent model.

- Agile development and agile principles: introduction to agile frameworks (e.g., Scrum); overview of agile tools and environments; real-world case studies.

- The Rational Unified Process (RUP): introduction to RUP; requirements management; Unified Modeling Language (UML).

- The C4 model for software architecture.

- Principles and patterns of design; object-oriented design principles; software design patterns (GoF) and their use in solving real-world design problems.

- Antipatterns and code smells: identifying antipatterns and common code smells.

- Software refactoring: refactoring techniques and refactoring tools.

- Software quality: introduction to software quality models; quantitative metrics for software quality.

- Software architecture: introduction to software architecture models; Clean Architecture.

- Software testing: unit testing; integration testing; test-driven development (TDD).

- Software design supported by artificial intelligence.

- Team-based course project.
