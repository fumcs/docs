**Course syllabus:**

- Operational semantics. Program verification. Recursive types. Review of major approaches to program semantics; transition systems; program verification methods; formal type systems; inductive and abstract (tree-based) syntactic structures; functions and function calls; data semantics; semantic equivalence; semantics of parallel programming.

**References:**

- Winskel, G. (1994). The Formal Semantics of Programming Languages: An Introduction. MIT Press.

- Pierce, B. C. (2002). Types and Programming Languages. MIT Press.
