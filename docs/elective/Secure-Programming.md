**Course syllabus:**

- Introduction to security: definition of security; basic cryptographic concepts. Software security; distinction between security features and truly secure behavior; impact of security on the software engineering process; software quality requirements; classification of threats; models for secure software development (independent, distributed, centralized). Static and dynamic analysis: static analysis (limitations of static analysis, code review, modeling, algorithm analysis); dynamic analysis (penetration testing). Common vulnerabilities: buffer overflows; input validation; error and exception handling; security of web applications; access control; privacy. Existing standards and frameworks: ASVS/OWASP, CERT, secure SDLC, CLASP, Common Criteria. Source-code analysis tools: static analysis tools and dynamic analysis tools.
