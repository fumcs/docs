**Course syllabus:**

This course introduces the basic principles underlying modern computer systems, with an emphasis on how hardware and software interact to execute programs efficiently and reliably.

Topics include: review of computer organization at the register-transfer level; instruction set architectures (with an illustrative example such as 8086 or a RISC architecture); data representation; memory hierarchy (caches, main memory, secondary storage); input/output and basic bus structures; interrupts and exceptions; and an overview of operating system responsibilities (processes, memory management, file systems) at a conceptual level.

The course emphasizes how high-level language constructs are mapped to low-level operations, and how hardware and system software cooperate to implement these abstractions.

**References:**
