**Course syllabus:**

This course focuses on developing students’ practical skills in using statistical software to analyze data. It is intended to complement theoretical statistics courses by emphasizing hands-on work with real or realistic datasets.

Topics include: overview of the role of statistics in data science; introduction to a statistical software environment (such as Excel, JMP, R, or similar tools); data import, cleaning, and management; computation of descriptive statistics; creation of common statistical graphs (histograms, boxplots, scatterplots, time-series plots, bar charts, and pie charts) for univariate and multivariate data; basic exploratory data analysis; and simple inferential procedures implemented via software.

Laboratory sessions should occupy a substantial portion of the course, with students completing guided exercises and small projects using real datasets to practice data exploration and reporting.
