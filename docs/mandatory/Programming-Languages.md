**Course syllabus:**

This course studies the concepts and design principles underlying modern programming languages, independent of any specific syntax. Emphasis is placed on understanding language features and their implementation, as well as on formal reasoning about programs.

Topics include: lexical structure and parsing at a high level; binding, scope, and lifetime of variables; data types and type systems (static vs dynamic typing, type checking, polymorphism, type inference); control structures (sequencing, selection, iteration, recursion); parameter passing mechanisms; abstraction mechanisms (procedures, modules, objects); memory management (stack, heap, garbage collection); and basic concurrency constructs.

An introduction to formal semantics is provided (operational and/or denotational semantics at a simple level), together with basic program verification ideas. Examples are drawn from multiple language paradigms, such as imperative, functional, object-oriented, and logic programming.

**Teaching and learning strategies appropriate to the content and objectives:**

The course is best delivered using a mix of lectures, language case studies, and practical exercises. At least one non-imperative language (e.g., a functional language) should be used in assignments to illustrate alternative paradigms.
