**Course syllabus:**

This course introduces core concepts of scientific computing with an emphasis on linear algebra and numerical methods that are widely used in computational science and data analysis. The goal is to familiarize students with matrix-based thinking, numerical stability, and fundamental algorithms for solving linear systems, least-squares problems, eigenvalue problems, and related tasks. Concepts are illustrated through applications in statistics, machine learning, and other areas of computer science.

Topics include: review of matrices and vectors; norms and inner products; orthogonality and projections; LU decomposition; QR decomposition; least-squares and normal equations; conditioning and numerical stability; iterative methods for linear systems; basic eigenvalue algorithms; and the use of high-level numerical libraries in a scientific programming environment (for example, Python with NumPy/SciPy). Connections to optimization and machine learning are highlighted where appropriate.

An applied component of the course requires students to implement or experiment with key numerical algorithms on small to medium-sized problems using a scientific programming language, and to analyze accuracy, stability, and computational cost.
