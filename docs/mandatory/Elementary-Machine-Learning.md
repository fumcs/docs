**Course syllabus:**

This course introduces the fundamental concepts and methods of machine learning. Emphasis is placed on understanding the distinction between machine learning and classical statistical modeling, and on developing an intuitive and practical grasp of major supervised and unsupervised learning techniques. The course covers the general workflow of a machine learning project, including data preprocessing, feature engineering, model training, validation, and evaluation, as well as basic issues such as overfitting, bias–variance trade-off, and generalization.

Supervised learning topics include: linear regression, logistic regression, regularization, basic evaluation metrics, tree-based methods, bagging, random forests, boosting, support vector machines, and introductory neural networks. Unsupervised learning topics include clustering (e.g., k-means, hierarchical clustering, density-based methods) and dimensionality reduction (e.g., PCA and related techniques), with connections to linear algebra and optimization highlighted where appropriate.

An applied component requires implementing and experimenting with standard machine-learning algorithms using Python and common libraries (such as scikit-learn), focusing on practical aspects including data splitting, cross-validation, hyperparameter tuning, and correct performance reporting.

**Teaching and learning strategies appropriate to the content and objectives:**

The course should prioritize conceptual clarity and hands-on practice while providing the essential mathematical foundations needed to engage with the literature. In addition to lectures, learning should take place through laboratory sessions, programming assignments, and small projects using real or realistic datasets. Students are encouraged to compare multiple models for the same task and to reflect on issues such as interpretability, fairness, and robustness.

Programming assignments and mini-projects should reinforce theoretical material and help students experience the full machine-learning pipeline from raw data to deployable models in simple environments.
