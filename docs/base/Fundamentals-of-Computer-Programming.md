**Course syllabus:**

An introductory familiarity with computer architecture; an overview of the hardware components of a computer as a computational model; communication among components; description of the simplest primitive operations performed by this computational model; introduction of simple algorithms based on these primitive operations; examination of algorithms for elementary problems such as summing several numbers, computing averages, searching, and so on; introduction of a high-level programming language to implement the proposed algorithms; introduction of variables and constants; introductory familiarity with computer structure; programming and presenting language-independent algorithms; introduction of variables and constants; conditional and control statements; types of loops; methods and parameters; working with arrays and files; notion of runtime and memory consumption; notion of recursive algorithms; search and sorting algorithms.

**Teaching and learning strategies appropriate to the content and objectives:**

Given that several courses in this curriculum are devoted to programming, it is appropriate that this foundational course place primary emphasis on strengthening students’ problem-solving and algorithm-design skills. Including diverse and engaging examples and exercises, encouraging student participation in class discussions, and presenting multiple solution strategies for a given problem can motivate students to engage deeply with the course. Familiarizing students with websites that host programming contests and challenges, with various available instructional resources, and assigning a meaningful project will also be beneficial.

Note: If Python is used as the teaching language in this Fundamentals of Computer Programming course, the following syllabus may be adopted: introduction to algorithms; variables; input and output; control structures; iterative structures; functions; arrays; basic data structures in Python such as strings, lists, tuples, and dictionaries; common libraries such as NumPy and SciPy; operations on NumPy arrays (indexing and slicing, ufunc operations); working with files; variable scope; program debugging; searching and sorting; documentation; and libraries such as SymPy for symbolic mathematical operations and PyGame.
