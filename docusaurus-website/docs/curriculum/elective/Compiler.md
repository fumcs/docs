**Course syllabus:**

Introduction to compilers and their structure; overview of programming languages and grammars; lexical analysis and finite automata; syntax analysis (top-down and bottom-up parsing); error handling and recovery; operator precedence and associativity; semantic analysis and intermediate representations; code generation; code optimization at a basic level; and an introduction to automatic compiler generation tools.

**References:**

- Aho, A. V., Lam, M. S., Sethi, R., & Ullman, J. D. (2006). Compilers: Principles, Techniques, and Tools (2nd ed.). Addison-Wesley.

- Cooper, K. D., & Torczon, L. (2011). Engineering a Compiler (2nd ed.). Morgan Kaufmann.
