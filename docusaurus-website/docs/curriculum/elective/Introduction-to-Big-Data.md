**Course syllabus:**

This course introduces the fundamental concepts, architectures, and technologies for managing and analyzing large-scale data sets. It focuses on the characteristics of big data (volume, velocity, variety, veracity, and value) and on the challenges they pose for data storage, processing, and analysis.

Topics include: big data architectures (batch and stream processing, Lambda and Kappa architectures); distributed file systems and storage (HDFS and related systems); data ingestion, cleaning, and preprocessing; programming models for big data (MapReduce, Spark RDDs and DataFrames); NoSQL databases and scalable data stores (key-value, column-oriented, and document-oriented systems); integration of big data platforms with machine learning and data mining; and basic issues of scalability, fault tolerance, and performance.

The course also provides an overview of widely used big data platforms and tools (Hadoop ecosystem, Spark, Hive, Cassandra, MongoDB) and discusses ethical, legal, and organizational aspects of working with large and potentially sensitive data sets.
