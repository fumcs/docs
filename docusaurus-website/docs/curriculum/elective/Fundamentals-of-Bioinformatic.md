**Course syllabus:**

This course introduces computational methods for the analysis of biological data. Topics include: basic molecular biology relevant to bioinformatics; sequence alignment; database search; motif finding; phylogenetic tree reconstruction; and an introduction to genomics and proteomics.

**References:**

- Pevsner, J. (2015). Bioinformatics and Functional Genomics (3rd ed.). Wiley-Blackwell.
