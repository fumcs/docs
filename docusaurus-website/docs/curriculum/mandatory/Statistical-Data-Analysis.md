**Course syllabus:**

This course introduces key concepts and methods for analyzing data using statistical techniques, with emphasis on exploratory data analysis, visualization, and basic inference.

Topics include: role of statistics in data science; types of data (quantitative, categorical, time series, multivariate); data collection and sources (including administrative and register data); descriptive statistics for univariate quantitative data (measures of central tendency and dispersion, quantiles) and for categorical data (proportions and related measures); graphical methods for univariate data (histograms, frequency curves, empirical distributions, normal curves, stem-and-leaf plots, bar charts, boxplots, time-series plots).

Bivariate and multivariate descriptions: cross-tabulations; bar charts and mosaic plots for categorical data; scatterplots and correlation for quantitative variables; visual comparison of two or more time series; graphical comparison of means across groups using boxplots and other suitable diagrams. An introduction to hypothesis testing (at an elementary level) is also provided.
