**Course syllabus:**

Basic concepts (data, metadata, data structures, and data models); principles of database design (conceptual modeling, ER diagrams, normalization); evolution of database systems (file-based, network, relational, object-oriented, object-relational, multidimensional); introduction to database management systems and comparison of different technologies; practical use of a DBMS (such as SQL Server, Oracle, or MySQL); SQL language: creation, deletion, and modification of databases, tables, and views; insertion, deletion, and modification of data; data querying, sorting, conditional selection, and formatting of query results; computational and aggregate functions; joins of two or more tables; introduction to big data analytics using modern database tools (e.g., SQL Server, Spark); and an overview of non-relational (NoSQL) databases.
