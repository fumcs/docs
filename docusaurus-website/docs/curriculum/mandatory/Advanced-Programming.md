**Course syllabus:**


- Integrated development environments

- Control and selection structures; functions and recursive functions; arrays and passing arrays as parameters

- Object-oriented programming: objects and their definition; identifying objects in a problem; relationships among objects

- Inheritance in object-oriented programming and polymorphism in object-oriented programming

- Exception handling

- Graphical user interfaces and the notion of interfaces

- Working with files

- Data streams

- Working with strings and arrays

- Dynamic memory

- If C++ is used in this course, the new features added to the C++ standards, collectively referred to as Modern C++, should be presented, including the following:

Templates; namespaces; `auto`; range-based `for` loop, `for each` loop; `Array` class; vectors; raw pointers and smart pointers; `String` class; lambda expressions; containers and algorithms

**Teaching and learning strategies appropriate to the content and objectives:**

**It is recommended that Modern C++ be taught in this course**, and that at the end, in one or two sessions, students also become acquainted with Java (or conversely). Through coordination between the instructors of this course and the Data Structures course, these two programming languages should be covered across both courses. That is, if C++ is taught in this course, then Data Structures should be taught with Java, and vice versa.
