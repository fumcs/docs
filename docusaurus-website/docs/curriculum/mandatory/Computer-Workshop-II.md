**Course syllabus:**

- Familiarity with version control systems and GitHub

- Familiarity with documentation tools such as Sphinx and MkDocs

- Group-work and project management services such as Slack, Trello, and Doodle

- Introduction to computer networks

- Overall structure of networks and the Internet; search engines; basic concepts such as URL and IP; familiarity with common protocols such as FTP, HTTP, and IMAP; and familiarity with commonly used network commands such as `ipconfig`, `ping`, and `traceroute`

- Familiarity with the skill sets required of back-end and front-end developers

- Introduction to UML
