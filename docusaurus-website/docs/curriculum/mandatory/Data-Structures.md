**Course syllabus:**

Time and space complexity analysis of algorithms; recursive functions; introduction to fundamental data structures (linked lists, stacks, queues, and priority queues) and their associated algorithms; representation of matrices in memory; sparse matrices; string matching; trees and tree traversal algorithms; expression trees and conversion between different expression notations; hashing and hash tables; graphs and graph algorithms (such as BFS and DFS); and basic search and sorting algorithms.
